## 🚀 运行测试

### 运行全部测试
```bash
npm run test:e2e
```

### 按类别运行
```bash
# 仅冒烟测试
npm run test:e2e -- smoke/

# 仅功能测试
npm run test:e2e -- projects/ agents/ sessions/ settings/ mcp/

# 仅边界情况
npm run test:e2e -- edge-cases/

# 仅性能测试
npm run test:e2e -- performance/
```

### 调试模式
```bash
# UI 模式
npm run test:e2e:ui

# 调试特定测试
npm run test:e2e -- projects/projects.spec.ts --debug
```

## 💡 最佳实践

1. **数据隔离**: 每个测试使用独立数据
2. **Mock 优先**: API 调用使用 mock 数据
3. **等待策略**: 优先使用自动等待，避免固定延时
4. **错误截图**: 失败时自动截图保存
5. **重试机制**: CI 环境自动重试 flaky 测试
